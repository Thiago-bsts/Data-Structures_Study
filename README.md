# 📚 Data Structures Study Repository

Este repositório foi criado com o objetivo de desenvolver uma base sólida em **Estruturas de Dados**, aplicando conceitos fundamentais em múltiplas linguagens de programação e evoluindo para aplicações práticas.

O foco não é apenas implementar, mas **entender profundamente, comparar abordagens e aplicar em problemas reais**.

---

## 🚀 Objetivos

* Dominar as principais estruturas de dados
* Desenvolver raciocínio lógico e resolução de problemas
* Comparar implementações entre diferentes linguagens
* Aplicar conceitos em projetos práticos
* Criar uma base sólida para entrevistas técnicas e projetos reais

---

## 🧠 Conteúdos abordados

* Arrays
* Linked Lists
* Stacks
* Queues
* Trees
* Graphs
* Hash Tables
