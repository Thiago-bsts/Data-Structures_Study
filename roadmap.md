# 🗺️ Roadmap — Data Structures Study

Este roadmap define a trilha de estudos em Estruturas de Dados, com foco em **domínio conceitual, implementação prática e aplicação real**.

---

## 🎯 Objetivo

Construir uma base sólida em estruturas de dados para:

* Resolver problemas com eficiência
* Escrever código otimizado
* Aplicar em sistemas reais
* Se preparar para entrevistas técnicas

---

## 📊 Como usar este roadmap

Para cada tópico:

* [ ] Estudar teoria
* [ ] Escrever resumo em `notes/`
* [ ] Implementar em pelo menos 2 linguagens
* [ ] Resolver no mínimo 3 problemas
* [ ] Criar 1 mini projeto (quando aplicável)
